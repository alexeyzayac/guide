# `ncdu` – интерактивный анализ дискового пространства

`ncdu` (NCurses Disk Usage) — это интерактивный анализатор дискового пространства с удобным текстовым интерфейсом на базе библиотеки ncurses. Если `du` хорош для быстрой оценки, то `ncdu` превращает поиск «пожирателей» места в интерактивное приключение с наглядными графическими полосками, возможностью навигации по каталогам и даже удалением ненужных файлов

## ⚙️ Популярные команды (быстрый старт)
```bash
# 1. Анализ текущего каталога
ncdu

# 2. Анализ корневой файловой системы (требует sudo)
sudo ncdu /

# 3. Анализ домашней директории
ncdu /home/user

# 4. Тихий режим (обновление раз в 2 секунды) – полезно по SSH
ncdu -q /var

# 5. Не выходить за пределы одной файловой системы (исключить смонтированные диски)
ncdu -x /

# 6. Исключить файлы по маске (например, логи)
ncdu --exclude "*.log" /var
```

## 📖 Полезные опции (таблица)

| Опция               | Длинная форма         | Назначение                                                                                   |
| ------------------- | --------------------- | -------------------------------------------------------------------------------------------- |
| `-h`                | `--help`              | Показать справку и выйти                                                                     |
| `-v`, `-V`          | `--version`           | Показать версию и выйти                                                                      |
| `-q`                | `--slow-ui-updates`   | **Тихий режим** – обновление экрана раз в 2 секунды вместо 10. Экономит трафик по SSH        |
| `-x`                | `--one-file-system`   | Не выходить за пределы одной файловой системы (игнорировать смонтированные разделы)          |
| `-e`                | `--extended`          | **Расширенный режим** – добавляет владельца, права доступа и время модификации (+30% памяти) |
| `-r`                | –                     | **Только чтение** – запрещает удаление файлов и выполнение команд из интерфейса              |
| `-o FILE`           | –                     | **Экспорт** – сохранить результаты сканирования в файл (без открытия интерфейса)             |
| `-f FILE`           | –                     | **Импорт** – загрузить ранее сохранённый файл с результатами                                 |
| `--exclude PATTERN` | –                     | Исключить файлы/каталоги, соответствующие шаблону (можно использовать несколько раз)         |
| `-X FILE`           | `--exclude-from FILE` | Исключить файлы по шаблонам из указанного файла (по одному на строку)                        |
| `--exclude-caches`  | –                     | Исключать каталоги, содержащие `CACHEDIR.TAG                                                 |
| `-L`                | `--follow-symlinks`   | Следовать по символическим ссылкам (по умолчанию – нет)                                      |
| `--si`              | –                     | Использовать десятичные приставки (1 MB = 1000 KB) вместо двоичных (1 MiB = 1024 KiB)        |
| `--color SCHEME`    | –                     | Задать цветовую схему (`off`, `dark`, `dark-bg`)                                             |
| `--confirm-delete`  | –                     | Подтверждать удаление файлов                                                                 |
| `--confirm-quit`    | –                     | Подтверждать выход из программы                                                              |
## 🧪 Расширенные примеры команд
```bash
# 1. Анализ с расширенной информацией (владельцы, права, время)
ncdu -e /home

# 2. Экспорт результатов в файл для последующего анализа
ncdu -o /tmp/disk_scan.json /var

# 3. Импорт ранее сохранённых результатов (без повторного сканирования)
ncdu -f /tmp/disk_scan.json

# 4. Исключить все .log и .tmp файлы
ncdu --exclude "*.log" --exclude "*.tmp" /var/log

# 5. Анализ корневой ФС, только на одном разделе, без сетевых дисков
sudo ncdu -x /

# 6. Тихий режим с расширенной информацией для удалённого сервера
ncdu -q -e /home/user
```
