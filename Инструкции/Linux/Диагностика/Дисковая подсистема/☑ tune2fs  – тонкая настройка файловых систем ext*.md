# `tune2fs` – тонкая настройка файловых систем ext2/ext3/ext4
**`tune2fs`** – это мощная утилита для изменения параметров файловых систем **ext2, ext3 и ext4** без их пересоздания[reference:0][reference:1]. Она позволяет настраивать поведение файловой системы, управлять резервными блоками, журналированием, метками и многим другим. Это незаменимый инструмент для системных администраторов, которые хотят оптимизировать производительность или изменить параметры уже существующего раздела.

## ⚙️ Популярные команды (быстрый старт)
```
# 1. Просмотреть все текущие параметры файловой системы
sudo tune2fs -l /dev/sda1

# 2. Установить максимальное количество монтирований перед проверкой (например, 30)
sudo tune2fs -c 30 /dev/sda1

# 3. Установить интервал между проверками (например, 30 дней)
sudo tune2fs -i 30d /dev/sda1

# 4. Изменить метку тома на "MyData"
sudo tune2fs -L MyData /dev/sda1

# 5. Установить процент резервных блоков для root (например, 2%)
sudo tune2fs -m 2 /dev/sda1

# 6. Добавить журнал (превратить ext2 в ext3)
sudo tune2fs -j /dev/sda1
```
## 🧪 Расширенные примеры команд
```bash
# 1. Просмотр полной информации о файловой системе (включая UUID, размеры, статус)
sudo tune2fs -l /dev/sda1

# 2. Установить проверку каждые 20 монтирований (с разбросом 20–40)
sudo tune2fs -c random /dev/sda1

# 3. Установить проверку раз в месяц и отключить проверку по числу монтирований
sudo tune2fs -c 0 -i 1m /dev/sda1

# 4. Изменить метку тома на "BACKUP" (не более 16 символов)
sudo tune2fs -L BACKUP /dev/sda1

# 5. Установить резервные блоки для root в 2% (освободить место для пользователей)
sudo tune2fs -m 2 /dev/sda1

# 6. Отключить резервные блоки полностью (ОПАСНО! только если диск не системный)
sudo tune2fs -m 0 /dev/sdb1

# 7. Добавить журнал на существующую ext2 (превратить в ext3)
sudo tune2fs -j /dev/sda1

# 8. Настроить поведение при ошибках: перемонтировать в read-only
sudo tune2fs -e remount-ro /dev/sda1

# 9. Включить расширения ext4 на существующей ext3 (требуется размонтирование)
sudo tune2fs -O extents,uninit_bg,dir_index /dev/sda1

# 10. Принудительно установить счётчик монтирований (вызвать проверку при загрузке)
sudo tune2fs -C 40 /dev/sda1
```
