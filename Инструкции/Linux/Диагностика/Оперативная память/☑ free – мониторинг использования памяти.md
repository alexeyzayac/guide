# `free` – мониторинг использования памяти

**`free`** – стандартная утилита Linux, показывающая количество свободной и занятой оперативной памяти (RAM) и пространства подкачки (swap) в системе. Она читает информацию из `/proc/meminfo` и представляет её в удобном для анализа виде. Незаменима для быстрой оценки загрузки памяти, поиска утечек и планирования ресурсов.

## ⚙️ Быстрый старт (основные команды)
```bash
# 1. Показать память в человеко-читаемом формате (KiB, MiB, GiB)
free -h

# 2. Показать в мегабайтах (MiB)
free -m

# 3. Обновлять данные каждые 2 секунды (интерактивный мониторинг)
free -s 2

# 4. Обновлять 5 раз с интервалом 3 секунды
free -s 3 -c 5

# 5. Показать сводку по строкам 
free -h -t 
```
## 📖 Полезные опции (таблица)
|Опция|Длинная форма|Назначение|
|---|---|---|
|**Единицы измерения**|||
|`-b`|`--bytes`|Вывод в байтах|
|`-k`|`--kilo`|Вывод в килобайтах (KiB = 1024 байт) – по умолчанию|
|`-m`|`--mega`|Вывод в мегабайтах (MiB)|
|`-g`|`--giga`|Вывод в гигабайтах (GiB)|
|`-h`|`--human`|Человеко-читаемый формат (автовыбор единиц, основание 1024)|
|`--si`|–|Использовать десятичные приставки (1 MB = 1000 KB) вместо двоичных (1 MiB = 1024 KiB)|
|`-l`|`--lohi`|Показать статистику по Low и High памяти (для старых систем)|
|**Управление выводом**|||
|`-t`|`--total`|Добавить итоговую строку (RAM + swap)|
|`-o`|`--old`|Вывод в старом формате (без колонки `available`)|
|`-w`|`--wide`|Широкий вывод (объединяет `buff` и `cache` в одну колонку)|
|`-c`|`--count`|Количество повторных выводов (используется с `-s`)|
|`-s`|`--seconds`|Интервал обновления в секундах (непрерывный режим)|
|`-V`|`--version`|Показать версию|
|`--help`|–|Справка|
## 🧪 Расширенные примеры команд
```bash
# 1. Мониторинг в реальном времени с обновлением каждую секунду
free -h -s 1

# 2. Вывести 3 отчёта с интервалом 5 секунд и итоговой строкой
free -m -t -s 5 -c 3

# 3. Использовать десятичные единицы (MB, GB) и человеко-читаемый формат
free --si -h

# 4. Старый формат (без available) для совместимости со скриптами
free -o -m

# 5. Широкий формат (buff/cache объединены) и итог
free -w -t -h

# 6. Получить только значение свободной памяти в мегабайтах (для скриптов)
free -m | awk '/Mem:/ {print $4}'
```
### Расшифровка строк и столбцов

|Строка|Описание|
|---|---|
|**Mem**|Оперативная память (RAM)|
|**Swap**|Пространство подкачки (swap) – используется, когда RAM заполнена|

|Столбец|Значение|Что означает|
|---|---|---|
|**total**|Общий объём памяти|Физический объём RAM или swap|
|**used**|Используемая память|`total - free - buff/cache` (включает буферы и кэш)|
|**free**|Совершенно свободная память|Не используется ничем|
|**shared**|Память, разделяемая между процессами|Обычно используется для tmpfs и разделяемой памяти (shm)|
|**buff/cache**|Буферы и кэш ядра|Память, занятая кэшем файловой системы и буферами ввода-вывода. Может быть освобождена при необходимости|
|**available**|**Доступная память**|Реалистичная оценка памяти, доступной для новых приложений (без учёта swap). Это – важнейший показатель!|
