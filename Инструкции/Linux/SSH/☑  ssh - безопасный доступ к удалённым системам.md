# `ssh` – безопасный доступ к удалённым системам

**`ssh`** (от *Secure Shell*) – это протокол и одноимённая клиентская утилита для защищённого удалённого доступа к Linux/Unix-системам. Она обеспечивает шифрование всех передаваемых данных, аутентификацию и возможность выполнения команд на удалённом хосте. `ssh` полностью заменил небезопасные протоколы `telnet` и `rsh` и стал стандартом де-факто для администрирования серверов.

## ⚙️ Быстрый старт (основные команды)
```bash
# 1. Подключение к серверу с указанием пользователя
ssh user@192.168.1.100

# 2. Выполнение команды без интерактивного входа
ssh user@server.com 'ls -la /var/log'

# 3. Подключение с использованием ключа (без пароля)
ssh -i ~/.ssh/mykey user@host

# 4. Подключение с пробросом X11 (графические приложения)
ssh -X user@host

# 5. Копирование файлов через SSH (встроенный SCP)
scp file.txt user@host:/home/user/
```

## 📖 Полезные опции (таблица)
| Короткая опция | Длинная опция | Назначение |
| --- | --- | --- |
| `-p` | `--port` | Указать порт (по умолчанию 22) |
| `-i` | `--identity-file` | Использовать указанный закрытый ключ |
| `-F` | `--config` | Использовать альтернативный файл конфигурации |
| `-v` | `--verbose` | Подробный вывод (отладка); `-vvv` для ещё большей детализации |
| `-q` | `--quiet` | Тихий режим (подавлять предупреждения) |
| `-4` / `-6` | – | Использовать только IPv4 / IPv6 |
| `-o` | `--option` | Передать опцию в формате `ключ=значение` (например `-o ServerAliveInterval=60`) |
| `-L` | `--local-forward` | Локальный проброс портов (forward) |
| `-R` | `--remote-forward` | Удалённый проброс портов |
| `-D` | `--dynamic-forward` | Динамический проброс (SOCKS-прокси) |
| `-N` | `--no-command` | Не выполнять удалённую команду (только проброс портов) |
| `-f` | `--fork` | Перейти в фоновый режим после аутентификации |
| `-X` | `--X11` | Включить проброс X11 (для графических приложений) |
| `-Y` | `--trusted-X11` | Включить доверенный проброс X11 (менее безопасно) |
| `-t` | `--tty` | Принудительно выделить псевдо-терминал (для интерактивных команд) |
| `-T` | `--no-tty` | Не выделять псевдо-терминал |
| `-C` | `--compress` | Включить сжатие данных (экономит трафик) |
| `-A` | `--forward-agent` | Пробросить SSH-агент (для цепочки подключений) |
| `-a` | `--no-forward-agent` | Отключить проброс агента |
| `-J` | `--proxy-jump` | Соединение через промежуточный хост (Jump Host) |

## 🧪 Расширенные примеры команд

```bash
# 1. Подключение к нестандартному порту (например, 2222)
ssh -p 2222 user@host

# 2. Использование ключа с парольной фразой (будет запрошен пароль к ключу)
ssh -i ~/.ssh/id_rsa user@host

# 3. Проброс локального порта 8080 на удалённый 80 (HTTP сервер)
ssh -L 8080:localhost:80 user@host

# 4. Удалённый проброс порта (чтобы удалённый хост мог достучаться до локального сервиса)
ssh -R 9090:localhost:8080 user@host

# 5. Проброс динамического SOCKS-прокси (для браузера)
ssh -D 1080 user@host

# 6. Выполнение команды и немедленный выход с пробросом агента
ssh -A user@host 'sudo apt update && sudo apt upgrade -y'

# 7. Прыжок через бастион-хост (Jump Host)
ssh -J user@bastion host2

# 8. Подробный вывод для отладки
ssh -vvv user@host

# 9. Установка опции поддержания соединения (чтобы не отваливалось)
ssh -o ServerAliveInterval=60 -o ServerAliveCountMax=3 user@host

# 10. Сжатие трафика для медленных каналов
ssh -C user@host
```

## 🧠 Практические советы (от себя)

### 1. Генерация ключей и настройка аутентификации

```bash
# Создать пару ключей (рекомендуется ed25519)
ssh-keygen -t ed25519 -C "my_email@example.com"

# Или RSA (более совместим, но длиннее)
ssh-keygen -t rsa -b 4096 -C "my_email@example.com"

# Скопировать публичный ключ на сервер
ssh-copy-id user@host

# Если ssh-copy-id недоступен, вручную:
cat ~/.ssh/id_ed25519.pub | ssh user@host 'mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys'
```

### Конфигурационный файл ~/.ssh/config

```bash
Host *
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60
    ServerAliveCountMax 3
    Compression yes

Host myserver
    HostName 192.168.1.100
    User admin
    Port 2222

Host jump
    HostName bastion.example.com
    User juser

Host target
    HostName 10.0.0.5
    ProxyJump jump
    User root
```

### 3. Проброс портов (туннели)

```bash
# Локальный проброс
ssh -L 8080:localhost:80 user@host

# Удалённый проброс
ssh -R 9090:localhost:8080 user@host

# Динамический проброс
ssh -D 1080 user@host
```

## 🔗 Связанные команды и файлы
* sshd – демон SSH (сервер)
* scp – безопасное копирование файлов (часть пакета OpenSSH)
* sftp – безопасный FTP-подобный интерфейс
* ssh-keygen – управление ключами
* ssh-copy-id – копирование ключа на сервер
* ssh-agent – менеджер ключей
* ssh-add – добавление ключа в агент
* mosh – мобильная оболочка для нестабильных сетей
* rsync – синхронизация файлов с использованием SSH
* sshfs – монтирование удалённой ФС через SSH
* ~/.ssh/config – файл конфигурации клиента
* /etc/ssh/sshd_config – конфигурация сервера
* ~/.ssh/authorized_keys – список публичных ключей для входа
* ~/.ssh/known_hosts – список ключей доверенных хостов
