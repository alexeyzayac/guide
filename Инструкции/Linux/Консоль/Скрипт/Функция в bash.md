## Контекст

Функции в bash - способ не дублировать код в скрипте: повторяющийся блок (логирование, проверка, retry) выносится в функцию и вызывается по имени. Аргументы передаются как при вызове скрипта: `$1`, `$2`, `$@`.

## Подсказки

- Объявление: `name() { … ; }` или `function name { … ; }`. Первый вариант - POSIX, работает везде.
- Возврат значения: `return N` ставит exit code (0-255), сам результат отдают через `echo`.
- Локальные переменные: `local var=…` (в bash, не в чистом sh).
- Вызов: `name arg1 arg2`, без скобок. Скобки только при объявлении.
`
```bash
cat > util.sh << 'EOF'
#!/bin/sh

greet () {
  arg1="$@"
  echo "hello, $arg1"
}

greet world
EOF
chmod +x util.sh
```
