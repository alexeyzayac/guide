# Работа с локальными Docker-образами

```bash
# Загрузить локальный Docker-образ в кластер (основной способ)
minikube image load nginx:latest -p zayac

# Альтернативный способ (устаревающий)
minikube cache add my-app:latest -p zayac

# Посмотреть список образов, загруженных в кластер
minikube image ls -p zayac

# Удалить образ
minikube image rm nginx:latest -p zayac
```
