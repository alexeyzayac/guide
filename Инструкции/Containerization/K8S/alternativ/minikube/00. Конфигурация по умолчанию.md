# Конфигурация по умолчанию

```bash
# Посмотреть все настройки конфигурации
minikube config view

# Установить драйвер по умолчанию (например, virtualbox)
minikube config set driver virtualbox

# Установить количество CPU по умолчанию
minikube config set cpus 2

# Установить объем памяти по умолчанию
minikube config set memory 2048

# Установить размер диска по умолчанию (например, 20 ГБ)
minikube config set disk-size 20g

# Сбросить настройку драйвера по умолчанию
minikube config unset driver

# Получить текущее значение настройки
minikube config get driver
```

## Драйвера

```bash
# Посмотреть список доступных и рекомендуемых драйверов для вашей системы
minikube drivers
```

| Драйвер    | Флаг                  | Поддерживаемые ОС     | Тип       | Кратко                                                 |
|------------|-----------------------|-----------------------|-----------|--------------------------------------------------------|
| Docker     | `--driver=docker`     | Linux, macOS, Windows | Контейнер | Рекомендуемый и самый универсальный; требует Docker    |
| Podman     | `--driver=podman`     | Linux                 | Контейнер | Экспериментальный; требует Podman                      |
| VirtualBox | `--driver=virtualbox` | Linux, macOS, Windows | VM        | Классический вариант; требует VirtualBox               |
| KVM2       | `--driver=kvm2`       | Linux                 | VM        | Рекомендуемый VM-драйвер на Linux; требует KVM         |
| QEMU       | `--driver=qemu`       | Linux, macOS          | VM        | Использует QEMU                                        |
| HyperKit   | `--driver=hyperkit`   | macOS                 | VM        | Для Intel Mac; считается устаревающим                  |
| Hyper-V    | `--driver=hyperv`     | Windows               | VM        | Встроенный гипервизор Windows Pro/Enterprise/Education |
| VMware     | `--driver=vmware`     | macOS, Linux, Windows | VM        | VMware Fusion / Workstation                            |
| Parallels  | `--driver=parallels`  | macOS                 | VM        | Требует Parallels Desktop                              |
| vfkit      | `--driver=vfkit`      | macOS                 | VM        | Через Virtualization.framework                         |
| krunkit    | `--driver=krunkit`    | macOS                 | VM        | Экспериментальный драйвер для macOS                    |
| None       | `--driver=none`       | Linux                 | Хост      | Запуск компонентов прямо на хосте; нужны root-права    |
| SSH        | `--driver=ssh`        | Удалённый Linux-хост  | Удалённо  | Запуск Minikube на удалённой машине по SSH             |
