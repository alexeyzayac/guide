# Приложения сервисы адоны

## Работа с аддонами

```bash
# Посмотреть список всех доступных и включенных аддонов
minikube addons list -p zayac

# Включить аддон (например, dashboard для веб-интерфейса)
minikube addons enable dashboard -p zayac

# Включить ingress-контроллер (необходим для внешнего доступа к сервисам)
minikube addons enable ingress -p zayac

# Включить metrics-server (для работы команд `kubectl top`)
minikube addons enable metrics-server -p zayac

# Отключить аддон
minikube addons disable dashboard -p zayac

# Включить аддон сразу при старте кластера
minikube start --addons=dashboard,ingress,metrics-server -p zayac
minikube start --addons=dashboard,ingress --addons=metrics-server -p zayac
```

## Доступ к приложениям и сервисам:

```bash
# Открыть Kubernetes Dashboard в браузере
minikube dashboard -p zayac

# Получить только URL для Dashboard, без открытия браузера
minikube dashboard --url -p zayac

# Получить список всех сервисов с их URL
minikube service list -p zayac

# Открыть сервис в браузере (для NodePort или LoadBalancer)
minikube service nginx-deployment-svc -p zayac

# Получить только URL сервиса, без открытия браузера
minikube service nginx-deployment-svc --url -p zayac

# Запустить туннель для сервисов типа LoadBalancer (должен работать в отдельном терминале)
minikube tunnel -p zayac
```
