# kubectl get

### `kubectl describe` — это ваш главный инструмент для диагностики и получения детальной информации о любом ресурсе Kubernetes.  В отличие от get, она не просто перечисляет объекты, а показывает их полное состояние, конфигурацию, условия, события и историю изменений.

Базовая структура команды выглядит так:
```bash
kubectl describe [RESOURCE] [NAME] [flags]
```

---

### Что можно получить?

| Ресурс	            | Команда                                     |
|-----------------------|---------------------------------------------|
| Поды	                | `kubectl describe pod <pod-name>`           |
| Узлы	                | `kubectl describe node <node-name>`         |
| Сервисы	            | `kubectl describe svc <svc-name>`           |
| Деплойменты           | `kubectl describe deploy <deploy-name>`     |
| ReplicaSets           | `kubectl describe rs <rs-name>`             |
| ConfigMap / Secret    | `kubectl describe cm <cm-name>`             |
| PersistentVolumes	    | `kubectl describe pv <pv-name>`             |
| Namespaces            | `kubectl describe ns <ns-name>`             |
| Любой CRD	            | `kubectl describe <crd-resource> <name>`    |

**Если не указать имя, describe выдаст информацию обо всех объектах указанного типа (но это редко полезно из-за объёма вывода).**

---

### Что показывает `describe`?

Вывод состоит из нескольких блоков (для пода, например):
* Общая информация — имя, namespace, узлы, IP, фаза, стартовое время.
* Спецификация (Spec) — контейнеры, образы, команды, порты, volumes, переменные окружения, ресурсы (CPU/память).
* Статус (Status) — условия (PodScheduled, Ready, Initialized, ContainersReady), последнее состояние контейнеров, причины перезапусков.
* События (Events) — хронология событий, связанных с этим подом (например, неудачные запуски, ошибки образа, проблемы с узлом, создание/удаление).

---

### Дополнительные флаги:

| Флаг	                    | Назначение                                                                |
|---------------------------|---------------------------------------------------------------------------|
| --show-events=true/false  | Показывать/скрывать блок событий (по умолчанию true)                      |
| --chunk-size	            | Для больших кластеров — размер пачки при получении данных (редко нужно)   |
| --ignore-not-found        | Не выдавать ошибку, если объект не найден                                 |
| -v, --v=<level>	        | Уровень детализации логирования (не влияет на вывод `describe`)           |


**`describe` не поддерживает выбор по меткам (`-l`) или полям (`--field-selector`) — она работает только с конкретным объектом по имени.**
