#### Режим 1: Vagrant + VirtualBox
````bash
sudo systemctl enable --now vboxdrv.service
sudo systemctl disable --now libvirtd
sudo systemctl disable --now libvirtd.socket
sudo modprobe -r kvm_intel
sudo modprobe -r kvm_amd
sudo modprobe -r kvm
````
Проверка, при выводе должно быть пусто.
````bash
lsmod | grep kvm
````
Добавь пользователя в группу (один раз).
```bash
sudo usermod -aG vboxusers $USER
newgrp vboxusers
```

#### Режим 2: KVM / libvirt / k8s / minikube
````bash
sudo systemctl disable --now  vboxdrv.service
sudo modprobe -r vboxdrv
sudo modprobe kvm
sudo modprobe kvm_intel
sudo systemctl enable --now libvirtd
````
Проверка, при выводе должно быть пусто.
````bash
lsmod | grep kvm
virsh list --all
````
Добавь пользователя в группу (один раз).
````bash
sudo usermod -aG libvirt $USER
newgrp libvirt
````
